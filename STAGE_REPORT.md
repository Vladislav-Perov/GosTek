## Этап 3. Сервер (Cloudflare Worker)
- **Статус:** 🏆 Завершено
- **Что сделано:**
  1. **Архитектура каскада моделей и универсальный адаптер:**
     - `server/worker.js` переведён на динамический каскад, настраиваемый через `env.MODELS_CASCADE` с fallback-списком (Gemini 2.5 Flash, Gemini 2.0 Flash, DeepSeek Chat, Groq Llama 3.1 8B).
     - Реализован универсальный адаптер `callOpenAiCompatible`, поддерживающий любой OpenAI-совместимый API (DeepSeek, Groq, Together, Mistral, Ollama).
  2. **Дедлайны, лимиты и строгая валидация JSON:**
     - Установлен общий дедлайн выполнения 15 секунд с использованием `AbortController` и `signal` во всех вызовах `fetch`.
     - Ограничение размера входящего payload до 32 КБ (HTTP 413 при превышении).
     - Строгая валидация JSON-схемы ответа от LLM (`parseAndValidateOutput`). При получении некорректного JSON или битой схемы воркер автоматически переходит к следующей модели в каскаде, не возвращая мусор клиенту. При исчерпании всех моделей каскада возвращается структурированный HTTP 503.
  3. **Безопасность и конфиденциальность на сервере:**
     - Внедрен Zero-Text Logging: из логов Cloudflare полностью удалены любые тексты пользователя, системные промпты и фрагменты ошибок (`errText.slice`), логируются строго технические метаданные.
     - Добавлен серверный Regex Scrubber: вторая линия обороны, заменяющая случайные сырые PII (паспорта, телефоны, счета IBAN, УНП, email) на плейсхолдеры.
     - Добавлена защита от Prompt Injection в системный промпт воркера.
  4. **Руководство по развертыванию:**
     - Создан файл `server/DEPLOY.md` с подробной инструкцией по установке Wrangler, настройке секретов, деплою, проверке через curl и настройке Cloudflare WAF Rate Limiting (15–20 запросов в минуту на IP).
  5. **Клиентская оптимизация (`AiAssistantService.cs`, `FieldsPage.xaml`, `FieldsPage.xaml.cs`):**
     - Клиентский таймаут согласован с сервером (сокращен с 35s до 20s).
     - В панель индикатора набора текста ИИ добавлена интерактивная кнопка «Отмена» на базе `CancellationTokenSource`.
     - Добавлена отмена сетевого запроса при закрытии шторки чата.
     - Дружественные сообщения об ошибках на русском языке.
  6. **Метрики:**
     - Тесты: 223/223 пройдены.
     - Сборка Windows 10/11: 0 предупреждений, 0 ошибок (`-warnaserror`).
     - Сборка Android: 0 предупреждений, 0 ошибок (`-warnaserror`).

  3. Проверить перетаскивание окна на разных мониторах с масштабированием 100%, 125% и 150% DPI: геометрия области перетаскивания должна масштабироваться синхронно.
