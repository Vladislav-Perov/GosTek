# Новый сервис генерации текста GosTek

Новый Worker `gostek-text` работает независимо от прежнего прокси. Приложение отправляет POST на `/generate` по HTTPS. Тело содержит `message`, `kind` (`explanation` или `document_text`) и необязательное `previousText` для явно выбранного варианта или команды правки. Поля формы, профиль, шаблон, OCR и история чата в контракт не входят. Сервис не хранит сообщения. Провайдер получает замаскированный текст запроса и, при правке, замаскированный предыдущий вариант. Хранение на стороне провайдера зависит от настроек и условий аккаунта.

## Проверка и публикация

В аккаунте Cloudflare, которым владеет команда GosTek, создайте или включите поддомен Workers. Понадобится ключ аккаунта Groq, которому доступен `openai/gpt-oss-20b` со строгим JSON Schema. Установите лимит расходов у провайдера перед публикацией. В Worker настроено ограничение в 10 запросов в минуту по IP в пределах точки Cloudflare. Это ограничение снижает частоту обращений к публичному маршруту. Для широкого распространения приложения стоит добавить авторизацию и квоты на пользователя.

Из каталога `server/text` выполните:

```powershell
node --test worker.test.mjs
npx wrangler login
npx wrangler whoami
npx wrangler deploy
npx wrangler secret put GROQ_API_KEY
```

Wrangler запросит ключ через терминал. Храните его только в Cloudflare Secrets. Запишите HTTPS-адрес нового Worker из вывода деплоя и добавьте `/generate`.

```powershell
$endpoint = 'https://gostek-text.YOUR-SUBDOMAIN.workers.dev/generate'
$body = @{
    kind = 'explanation'
    message = 'I was 20 minutes late because the bus broke down. Draft the explanation.'
} | ConvertTo-Json -Compress
Invoke-RestMethod -Method Post -Uri $endpoint -ContentType 'application/json' -Body $body
```

Ожидается строка в `text` и `null` в `question`. Если модели нужно уточнение, ожидается обратное. При `503` проверьте секрет, доступ к модели и квоту у провайдера. Worker пишет технические категории ошибок и HTTP-статусы без содержимого запроса.

## Подключение приложения

Из корня репозитория:

```powershell
dotnet build GosTek.csproj -f net10.0-windows10.0.19041.0 -p:GosTekTextGenerationEndpoint=$endpoint
dotnet build GosTek.csproj -f net10.0-android -p:GosTekTextGenerationEndpoint=$endpoint
```

Передавайте этот же параметр при публикации. Сборка без адреса позволяет заполнить поле вручную и сообщает, что сервер генерации не настроен.

## Проверка в приложении

1. Откройте встроенную «Объяснительную записку». У поля основного текста нажмите «Сгенерировать текст». Введите вымышленную ситуацию. В пустом поле должна появиться только основная формулировка. Остальные поля должны остаться прежними.
2. Напишите «Сделай короче» или нажмите «Править этот вариант». Существующий текст должен измениться только после подтверждения. Проверьте отмену вставки.
3. Импортируйте свой DOCX с `{Текст}`. Если маркер повторяется, форма показывает одно поле, и при экспорте значение вставляется во все места. Шаблон без этого маркера заполняется вручную.
4. Перенесите распознанный текст из сканера. GosTek должен предложить локально выбрать многострочное поле. Чат при этом не открывается.
5. Отключите сеть. Введённый запрос должен остаться доступен для повтора, а документ — для ручного заполнения.
