## 📌 О проекте

GosTek решает проблему рутинного и подверженного ошибкам заполнения документов по официальным шаблонам (ГОСТ/СТБ, бланки гос. учреждений, формы для ИП). Вместо ручного переноса данных из бумажного документа в электронную форму — пользователь фотографирует или загружает документ, приложение распознаёт текст, определяет тип документа и автоматически заполняет нужный шаблон.

### 🔑 Ключевые отличия

| | |
|---|---|
| 🎯 **Заточка под РБ** | Сопоставление со структурой конкретного типа документа и валидация по требованиям стандарта — не просто OCR "текст в текст" |
| 🔒 **Полная локальность** | Документы и распознанные данные никогда не покидают устройство пользователя |

## 🛠️ Технологии

| Компонент | Технология |
