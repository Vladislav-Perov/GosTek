# GosTek

GosTek — приложение для Windows и Android. Оно заполняет шаблоны Word, экспортирует документы в DOCX и PDF, проверяет оформление по ГОСТ и помогает переносить данные из сканов.

[![GosTek CI](https://github.com/Vladislav-Perov/GosTek/actions/workflows/ci.yml/badge.svg?branch=main)](https://github.com/Vladislav-Perov/GosTek/actions/workflows/ci.yml)

**Текущая версия** — 0.45. **Android** — 10 и новее. **Windows** — настольная сборка на .NET 10 MAUI.

## Что умеет GosTek

- **Шаблоны.** В приложение встроено **70 эталонных шаблонов** в **19 категориях** («Заявления», «Договоры», «Служебные», «Учёба», «Студент», «Кадры», «Недвижимость», «Организация», «Предприниматель», «Преподаватель», «Работник», «Семья», «Строительство», «Торговля», «Примеры», «IT», «Авто», «Бизнес», «Гражданин»). Свой шаблон на Android можно импортировать через **Настройки → Шаблоны → Добавить DOCX**. На Windows нажмите **Открыть в проводнике** в том же разделе и скопируйте DOCX в открывшуюся папку. Для проверки генерации откройте **Примеры → Тестовая объяснительная с ИИ**. GosTek распознаёт поля вроде `{ФИО}` и `[Название поля-подсказка]`, подставляет реквизиты из профиля и показывает предпросмотр. Готовый документ можно сохранить в Word или экспортировать в PDF.
- **Инспектор оформления.** Откройте DOCX, выберите набор правил и проверьте поля страницы, шрифт, интервалы, отступы, нумерацию и другие параметры оформления. Доступные исправления можно применить по одному или группой. Результат сохраняется как отдельная копия `*_исправлено.docx`.
- **Сканер на Android.** Распознаёт текст (двухъязычный Tesseract `rus+eng`), разбирает машиночитаемую зону паспорта или ID-карты (ICAO 9303 MRZ с контрольной суммой 7-3-1) и предлагает перенести выбранные реквизиты в профиль. Распознанный текст можно локально вставить в поле шаблона или использовать для создания нового DOCX.
- **Оцифровка на Windows.** Выберите или перетащите JPG либо PNG, нажмите «Распознать текст» и сверьте результат с изображением. В этом же окне можно отредактировать текст, настроить оформление, посмотреть лист А4 и сохранить документ в Word или PDF. Распознавание выполняется на устройстве через Windows.Media.Ocr и использует установленные в Windows языки OCR.
- **Профиль.** Реквизиты хранятся в защищённом хранилище устройства (DPAPI на Windows, KeyStore AES-256 GCM на Android) и используются для заполнения шаблонов.
- **Быстрый интерфейс.** Каталог шаблонов использует виртуализацию `CollectionView` с `ItemSizingStrategy="MeasureFirstItem"`, дебаунс поиска 180 мс и фоновое обновление каталога. Ввод данных оптимизирован через `InputChrome` с акцентным 2px фокус-контуром.

## Генерация текста

Во встроенной **«Объяснительной записке»** нажмите **«Сгенерировать текст»** рядом с полем объяснения. Чтобы включить генерацию в своём DOCX, вставьте в нужное место маркер **`{Текст}`**. Повторяющиеся маркеры используют одно значение.

Чат возвращает фрагмент для одного поля или задаёт уточняющий вопрос. Готовый ответ сразу вставляется в пустое поле. Для замены введённого текста требуется подтверждение. Можно попросить сократить предыдущий вариант или отменить вставку.

Запросы обрабатывает Cloudflare Worker. Основная модель — **GPT-OSS 20B через Groq**, резервная — **Llama 3.3 70B через Cloudflare Workers AI**. GosTek отправляет сообщение, тип текста и предыдущий вариант при правке. Распознанные реквизиты маскируются локально. Профиль, DOCX, сканы и остальные поля остаются на устройстве. Генерация требует сети и согласия пользователя.

## Сборка и запуск

Установите .NET 10 SDK. Для Android также нужны Android SDK и JDK, совместимые с установленной нагрузкой .NET for Android. Команды запускаются из корня репозитория.

```powershell
dotnet workload restore GosTek.csproj
```

### Windows

```powershell
dotnet build GosTek.csproj -f net10.0-windows10.0.19041.0
& .\bin\Debug\net10.0-windows10.0.19041.0\win-x64\GosTek.exe
```

### Android

```powershell
dotnet build GosTek.csproj -f net10.0-android
```

На Windows подписанный тестовый APK появится в `bin\Debug\net10.0-android\com.companyname.gostek-Signed.apk`. Его можно перенести на Android-устройство или установить через ADB.

```powershell
adb install -r .\bin\Debug\net10.0-android\com.companyname.gostek-Signed.apk
```

Адрес сервера генерации уже задан в `GosTek.csproj`. Для своего сервера передайте `-p:GosTekTextGenerationEndpoint=https://example.com/generate` при сборке. Ключ Groq задаётся в Cloudflare Secrets.

## Тесты

В проекте реализован полный набор автоматических тестов (100% зелёные):
- **370 тестов** xUnit в `GosTek.Tests` (правила ГОСТ, парсер MRZ ICAO 9303, сидер 70 шаблонов, маскирование ПДн, шифрование профиля).
- **13 тестов** Node.js для серверных Cloudflare Workers (генерация текста, Zero-Text logging, обработка таймаутов и fallback).

```powershell
dotnet test GosTek.Tests/GosTek.Tests.csproj --nologo
node --test server/worker.test.mjs server/text/worker.test.mjs
```

Тесты приложения запускаются на Windows. Для тестов Worker используйте Node.js. GitHub Actions запускает оба набора тестов на pull request и при push в `main` или `dev/improvements`. При push в `main` также собирается Android-приложение. [Ручные сценарии проверки](docs/MANUAL_CHECKLIST.md)

## Структура проекта

| Каталог | Назначение |
|---|---|
| `Views/`, `Controls/` | Экраны и компоненты .NET MAUI (`TemplatesPage`, `FieldsPage`, `CheckPage`, `ScanPage`, `ProfilePage`, `ChipBar`, `ListRow`) |
| `Models/`, `Services/` | Каталог шаблонов (`TemplateSeeder`, 70 шаблонов), OpenXML-движок (`TemplateEngine`), инспектор DOCX, OCR/MRZ, экспорт и клиент генерации |
| `Platforms/`, `Resources/` | Платформенный код (Windows: WinRT OCR, QuestPDF; Android: `AndroidPdfWriter`, Tesseract `rus+eng`), встроенные ассеты |
| `server/` | Cloudflare Workers (`server/worker.js`, `server/text/worker.js`) и их тесты |
| `GosTek.Tests/` | Автотесты приложения на xUnit (370 тестов) |

Для работы с DOCX используется DocumentFormat.OpenXml 3.2.0. Для PDF-экспорта на Windows используется QuestPDF 2026.9.1, а на Android — нативный легковесный `AndroidPdfWriter` (`Android.Graphics.Pdf.PdfDocument`). Распознавание выполняют Windows.Media.Ocr на Windows и двухъязычный Tesseract 1.5.1 (`rus+eng`) на Android, а предобработку изображений выполняет SkiaSharp 4.155.0.
