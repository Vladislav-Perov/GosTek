## 📌 О проекте

**GosTek** решает проблему рутинного заполнения и проверки служебных, учебных и деловых документов. Приложение работает строго локально: персональные данные и файлы документов никогда не передаются во внешнюю сеть и обрабатываются исключительно на устройстве пользователя.

### Ключевые возможности

1. **Аудит оформления по ГОСТ (без ИИ):**
   - Прямой анализ структуры `.docx` через OpenXML SDK (поля страницы, гарнитура, кегль, межстрочный интервал, нумерация страниц).
   - Автоматическое устранение замечаний в один клик с сохранением исправленной копии.
2. **Шаблонизатор документов Word:**
   - Парсинг плейсхолдеров вида `[Название поля-подсказка]` и `{Название поля}`.
   - Подстановка значений с сохранением оригинального форматирования, поддержкой многострочных вставок и автозаполнением из профиля.
3. **OCR-сканирование паспорта гражданина РБ:**
   - Распознавание фото и сканов через нативные оффлайн-движки: Tesseract (Android) и `Windows.Media.Ocr` (Windows).
   - Автоматическое извлечение ФИО и серии/номера с нормализацией кириллических гомоглифов.
4. **Защищённый профиль организации и гражданина:**
   - Хранение реквизитов (УНП, IBAN с проверкой mod 97, паспорт, адрес) в зашифрованном системном хранилище `SecureStorage`.

## 🚀 Сборка и запуск

### Требования к окружению
- **.NET SDK:** `10.0.403` или новее.
- **Рабочие нагрузки (workloads):** `maui-windows`, `android`.

### Команды сборки и запуска

```bash
# 1. Запуск unit-тестов
dotnet test GosTek.Tests/GosTek.Tests.csproj

# 2. Сборка под Windows (строгий режим проверки предупреждений)
dotnet build GosTek.csproj -f net10.0-windows10.0.19041.0 -p:TreatWarningsAsErrors=true -warnaserror

# 3. Запуск десктопного приложения на Windows
dotnet run --project GosTek.csproj -f net10.0-windows10.0.19041.0

# 4. Сборка APK для Android
dotnet build GosTek.csproj -f net10.0-android
```

## 📂 Структура решения

- **[`GosTek.sln`](./GosTek.sln)** — главное решение проекта.
- **[`GosTek.csproj`](./GosTek.csproj)** — исходный код клиентского приложения:
  - `Views/` — экраны ContentPage (Главная, Шаблоны, Заполнение, Проверка ГОСТ, Сканирование паспорта, Профиль).
  - `Services/` — бизнес-логика (`DocumentChecker`, `TemplateEngine`, `ExportService`, `DocumentDataExtractor`, `OcrService`).
  - `Models/` — структуры данных и правила валидации (`CheckModels`, `TemplateDef`, `ProfileData`).
  - `Resources/` — векторная графика, шрифты PT Sans и языковая база Tesseract.
- **[`GosTek.Tests/`](./GosTek.Tests/)** — набор unit-тестов xUnit (валидация IBAN/УНП/паспортов, парсинг OCR, шаблонизация Run-элементов, аудит стилей OpenXML, защита от Path Traversal).

Проект начался как хакатонная разработка командой из 3 человек в октябре 2025 года (изначальный концепт-дедлайн — 25 октября). В процессе дальнейшего развития архитектура была полностью переработана под оффлайн-стек .NET 10 MAUI и доведена до рабочего стабильного релиза версии **v0.45**.
